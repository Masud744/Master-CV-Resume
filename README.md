## ⚙️ ATS Optimization Highlights

Both 1-page resumes in the `Resume/` folder strictly adhere to the standards outlined in [`ATS_OPTIMIZATION_GUIDE.md`](ATS_OPTIMIZATION_GUIDE.md):
- **100% Single-Column Layout:** Zero tables, text boxes, graphic progress bars, or multi-column grids that confuse Applicant Tracking Systems.
- **Taleo / Workday / Greenhouse Standard Headers:** Exact standard section naming (`Professional Summary`, `Technical Skills`, `Experience`, `Technical Projects`, `Education`, `Leadership & Activities`).
- **Standard Contact & Date Formats:** E.164-compliant phone parsing (`+880 1740-071118`), city-level location match (`Dhaka, Bangladesh`), and uniform 3-letter month abbreviations (`Sep`, `Aug`, `Apr`).
- **Strict 1-Page Constraint:** Exactly 1 page with zero dangling lines or spillover.
- **Real-World Metrics:** Impact quantified via the XYZ formula (e.g., `>90% accuracy`, `~4x inference speedup`, `35+ users & 3,500+ records`).
